L'essentiel

Darsio est un logiciel installé sur votre ordinateur. Les données de vos élèves (noms, codes Massar, notes, absences, remarques) sont enregistrées uniquement sur votre PC. Darsio ne les envoie à personne, et nous n'y avons pas accès.

Ce que fait l'application

  • Vérification des mises à jour : si vous l'activez, Darsio lit le fichier public darsio.pages.dev/version.json. Comme pour toute page web, notre hébergeur reçoit l'adresse IP de l'ordinateur ; aucune donnée d'élève n'est transmise.
  • Licence : pour acheter une licence, vous nous envoyez le code de votre PC (un identifiant technique de l'ordinateur, sans donnée personnelle) et vos coordonnées de contact.
  • Aucune mesure d'audience dans l'application, aucune publicité, aucun traceur.

Ce que fait le site darsio.pages.dev

  • Mesure d'audience sans cookie (Cloudflare Web Analytics) : nombre de visites, pages vues, pays ; aucun profil individuel.
  • Si vous nous écrivez (WhatsApp, e-mail), nous gardons votre message le temps de vous répondre et de gérer votre licence.

Vos droits

Conformément à la loi n° 09-08 relative à la protection des personnes physiques à l'égard du traitement des données à caractère personnel, vous disposez d'un droit d'accès, de rectification et d'opposition. Écrivez à contact@darsio.com.

Le professeur reste responsable des données de ses élèves qu'il enregistre dans Darsio, sur son propre ordinateur.
